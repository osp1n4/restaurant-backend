🎯 Objetivo de las Pruebas

Estas pruebas verifican la comunicación completa entre microservicios a través de RabbitMQ, incluyendo la publicación de eventos (Producer), el enrutamiento a través del broker, y el consumo de eventos (Consumer). Se valida también el manejo de errores, la persistencia de mensajes, y el comportamiento bajo carga.

  • Publicación de eventos desde Producer (Order Service)
  • Enrutamiento correcto a través del broker (RabbitMQ)
  • Consumo de eventos por múltiples Consumers (Services)
  • Manejo robusto de errores en la comunicación
  • Persistencia y acknowledgments de mensajes
  • Performance y latencia bajo diferentes cargas

⚙️ Configuración y Ejecución

Prerrequisitos

# 1. RabbitMQ debe estar corriendo
docker-compose up -d rabbitmq

# O usar contenedor standalone
docker run -d --name rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:3-management

# 2. Variable de entorno
RABBITMQ_URL=amqp://localhost:5672

# 3. Instalar dependencias
npm install amqplib @types/amqplib

Comando de Ejecución

# Ejecutar todas las pruebas de integración
npm test -- tests/integration/rabbitmq.integration.test.ts --verbose --forceExit --runInBand --testTimeout=20000

# Ejecutar solo un grupo específico
npm test -- tests/integration/rabbitmq.integration.test.ts -t "Connection Tests"

Opciones del Comando

  • --verbose: Muestra detalles de cada test
  • --forceExit: Fuerza salida después de completar tests
  • --runInBand: Ejecuta tests secuencialmente (importante para RabbitMQ)
  • --testTimeout=20000: Timeout de 20 segundos por test
